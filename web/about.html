About isitfast.cloud

A map of cafes and coworking spaces with the internet numbers that matter when you want to work from one. The ring in the logo is the test range: a speed test only counts if it was run within 50 m of the place.

Where the numbers come from

  • Mobile data (published) — quarterly averages from Speedtest® by Ookla® Global Fixed and Mobile Network Performance Maps, aggregated into ~600 m map tiles. All carriers are combined; Ookla's open data does not break results down by carrier. We show the tile containing the place, or the average of the surrounding tiles when that tile has no tests. Licensed CC BY-NC-SA 4.0.
  • Home/office broadband nearby — the fixed-network counterpart from the same Ookla dataset. It describes broadband in the area, not this place's WiFi.
  • This place's WiFi and mobile data by carrier — speed tests people run in their browser while at the place. Tests run against Cloudflare's nearest edge (our own endpoint, speed.isitfast.cloud, which signs how much data it actually sent and received so results can be checked; speed.cloudflare.com if ours is unreachable). On mobile data a test uses at most about 100 MB; the carrier or ISP is identified from the network's ASN. We show the latest test and when it ran. A test is accepted only if your device reports being within 50 m of the place. Your location is used for that check and is not stored with your test; the one exception is the first test at a Google-listed or newly named place, whose pin is placed where that test was run.
  • Map — Google Maps. Tap any cafe, restaurant, shop or office on the map and test it while you are there; it gets a labelled pin once tested. Place names and addresses are shown live from Google and are not stored by us — we keep only Google's place ID and the speed tests. Loading the map sends your browser's requests to Google (Google's privacy policy).
  • Places (the dots) — cafes, coworking spaces, restaurants, offices and apartment buildings from OpenStreetMap (© OpenStreetMap contributors), refreshed weekly, plus places named by visitors. Houses and other buildings appear once someone tests there.
  • Type and icons — Geist (SIL Open Font License); speed icon by Icons8.

Limitations

Ookla tile averages mix indoor and outdoor tests and every carrier; a single cafe can be much better or worse. Community WiFi tests are only as good as the number of people who run them — treat one test as a hint, not a verdict.
