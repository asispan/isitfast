# Security

Please report vulnerabilities privately through GitHub:
**Security → Report a vulnerability** on this repository. Do not open a public issue.

In scope: the API in `app/`, the speed Worker in `speed-worker/`, and the web client in `web/`
(for example test-result forgery, rate-limit bypass, receipt/HMAC weaknesses, injection).
Please include steps to reproduce. You'll get an acknowledgement within a few days.
